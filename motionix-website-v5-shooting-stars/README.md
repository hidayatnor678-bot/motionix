# MOTIONIX — Video Editing Studio

Website statis untuk GitHub Pages.

## File
- `index.html` — struktur halaman
- `style.css` — desain dan responsive layout
- `script.js` — navigasi, filter portfolio, dan form WhatsApp

## Sebelum dipublikasikan
1. Buka `script.js`.
2. Ganti `6280000000000` dengan nomor WhatsApp kamu (format 62, tanpa + atau spasi).
3. Ganti email `hello@motionix.studio` di `index.html` dengan email kamu.
4. Ganti contoh thumbnail portfolio dengan video/hasil edit asli kamu.
5. Upload semua file ke repository GitHub dan aktifkan GitHub Pages.

Catatan: kartu portfolio saat ini adalah placeholder desain, bukan klaim hasil proyek klien.
